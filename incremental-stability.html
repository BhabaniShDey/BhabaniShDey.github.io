A visual tour through incremental stability

Classical stability asks whether trajectories reach an equilibrium. Incremental stability asks something stronger: do any two trajectories forget where they started and converge to each other? This tour shows two ways to certify it, live in your browser. Pick a system, move the sliders, and watch the certificate succeed or fail.

Contraction and matrix measures

Start from a nonlinear system ẋ = f(x, t). Differentiate it to get the Jacobian J(x, t) = ∂f/∂x, which governs how two nearby trajectories move relative to each other. If the matrix measure of J is negative everywhere, in some metric Θ, every pair of trajectories converges. The dashboard below walks through these steps live.

Incremental stability in one line

A system ẋ = f(x, t) is contracting if every pair of trajectories converges to each other exponentially — independent of where they started:

‖x₁(t) − x₂(t)‖ ≤ K e^{−λt} ‖x₁(0) − x₂(0)‖

No equilibrium is needed. That is why it fits tracking, observers, synchronisation and systems driven by inputs.

The matrix-measure test

With Jacobian J = ∂f/∂x and a constant metric Θ, a sufficient condition is a uniformly negative matrix measure:

μ(Θ J(x,t) Θ⁻¹) ≤ c < 0 for all x, t

Here μ₂(A) = λmax((A + Aᵀ)/2), μ₁ uses column sums and μ∞ row sums. The rate is λ = −c and K = cond(Θ), up to norm-equivalence factors.

Things to try

Start nonlinear. In the forced network, J depends on the state through sech²(x) and sech²(y). Hover over the plane to see J and μ change point by point; lower a below b/2 and red patches appear where trajectories can separate.

Metric matters. In the linear system, A = [−1 4; 0 −1] is Hurwitz but μ₂(A) > 0. Increase s above 2 and the certificate appears.

Entrainment. In the forced network, contracting systems forget initial conditions and lock onto a single periodic response to the input.

Not contracting. Van der Pol trajectories reach the same limit cycle but keep their phase difference — the spread never decays.

Incremental Lyapunov functions

Instead of a matrix measure, build a function V(x, x̂) of two states that measures how far apart they are, and show it decreases along every pair of trajectories. Here V(x, x̂) = (x − x̂)ᵀ P (x − x̂). Drive the two copies with the same input to see δ-GAS, or give them different inputs to see the δ-ISS bound.

What an incremental Lyapunov function is

A function V(x, x̂) is an incremental Lyapunov function if it is sandwiched by the distance between its arguments and decreases along every pair of trajectories:

α₁(‖x − x̂‖) ≤ V(x, x̂) ≤ α₂(‖x − x̂‖)
V̇ ≤ −κ V(x, x̂)

Then V(t) ≤ e^{−κt} V(0), so every pair converges: the system is incrementally globally asymptotically stable (δ-GAS).

With inputs: δ-ISS

If the two copies receive different inputs u and û, ask instead for

V̇ ≤ −κ V + σ(‖u − û‖)

The pair no longer converges, but its distance settles inside a ball whose size grows with the input mismatch. This incremental input-to-state stability (δ-ISS) is the property used for Sim2Real bounds and learned controllers.

How the demo checks it

For a quadratic V = δᵀPδ with δ = x − x̂, the mean-value theorem gives V̇ ≤ c V whenever

JᵀP + PJ ≤ c P for all x in the box

The demo computes the largest generalised eigenvalue c(x) on a grid; the blue and red map shows its sign. With the input on x₂, ‖x − x̂‖ settles below 2√p₂₂ |δu| / (|c| √λmin(P)). A constant P is exactly a constant contraction metric Θ = P^{1/2}, so Stops 1 and 2 are two views of the same idea.

Things to try

The right P. In the linear system, P = I fails because A = [−1 4; 0 −1] is not normal. Press “Solve AᵀP + PA = −I” and the certificate appears.

Local, not global. For the pendulum, cos x₁ changes sign beyond |x₁| = π/2, so no constant P works everywhere. Shrink the box r to find where V is a valid certificate.

δ-ISS. Raise δu: the pair stops converging but stays inside the green bound, which scales linearly with δu.

In 3D. The pair is a ball sliding down the bowl V(δ). With a valid certificate it only goes down; with P = I on the linear system, watch it climb (red) before it falls.
